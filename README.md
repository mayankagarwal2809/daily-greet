# Daily Greet ✨ 👋

> A fresh, creative greeting for your team — every single day of the year!

![Daily Greet](https://img.shields.io/badge/greetings-366-blue?style=for-the-badge)
![Made with Love](https://img.shields.io/badge/made%20with-💛-ffc220?style=for-the-badge)

## 🚀 What is this?

**Daily Greet** is a fun, lightweight web app that gives you a **unique, creative greeting every day** to share with your team. 366 handcrafted greetings across 7 categories:

- ☀️ Warm & Classic
- 💻 Nerdy & Tech
- 💎 Motivational
- 🎬 Pop Culture
- 🌈 Seasonal
- 🍕 Food & Drink
- 🐝 Animal & Nature
- 🧘 Deep Thoughts
- 🎸 Wild & Wacky

## ✨ Features

- 🗓️ **One greeting per day** — seeded by date for consistency
- ⬅️➡️ **Browse past & future greetings** — arrow keys or buttons
- 📋 **Copy to clipboard** — share in Slack, Teams, email
- 📤 **Web Share API** — native sharing on mobile
- 🎨 **Beautiful UI** — Tailwind CSS, smooth animations
- ♿ **Accessible** — WCAG 2.2 AA, keyboard navigation, ARIA labels
- 📱 **Responsive** — works on any device

## 🛠️ Tech Stack

- Vanilla HTML/CSS/JavaScript (zero dependencies!)
- Tailwind CSS (via CDN)
- Google Fonts (Outfit)

## 🏃 Run Locally

Just open `index.html` in a browser. That's it. No build step. No bundler. No drama.

## 🚢 Deploy to Vercel

1. Push to GitHub
2. Import repo in [Vercel](https://vercel.com)
3. Done! ✅

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `←` | Previous day |
| `→` | Next day |
| `Home` / `Esc` | Back to today |
